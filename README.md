## Selected Projects

### [PuppyCare](https://github.com/ShaharKoza/PuppyCare)

[Project website](https://shaharkoza.github.io/PuppyCare/)

A real-time IoT monitoring and alerting system connecting a Python backend on Raspberry Pi, Firebase, and a native iOS app.

The system combines Python sensor-data ingestion and validation with profile-driven alert rules, cooldown intervals, and heartbeat monitoring. Firebase Realtime Database and Cloud Functions connect telemetry and alert events to the iOS client.

**Built with:** Python, Firebase Realtime Database, Cloud Functions, Raspberry Pi, SwiftUI  
**My contribution:** Developed jointly with Shahar Koza across the project.

### [SmartDay](https://github.com/daniellash161/smartday-v2)

[Project website](https://daniellash161.github.io/smartday-v2/)

A personal organization app that turns payment documents into structured data and actionable reminders.

It extracts text from PDFs and scanned documents, identifies transactions and recurring payments, and flags unusual charges using rules and statistical thresholds. It also integrates with Gmail and Google Calendar.

**Built with:** React, TypeScript, PDF.js, Tesseract.js  
**My contribution:** Developed most of the application as part of a team project.

### [AI MarketPulse](https://github.com/daniellash161/ai-marketpulse)
An academic project exploring market data analysis and forecasting through model comparison and interactive visualizations.

The application combines market data, technical indicators, simplified forecasting models, and historical strategy simulations. It includes chronological evaluation splits and experiments with combining model predictions.

**Built with:** React, TypeScript, Node.js, Express, Recharts  
**My contribution:** Developed most of the application as part of a team project.  
**Project status:** Submitted academic prototype with known data and evaluation limitations. Forecasts and simulation results are exploratory.
